# NixConfig

NixOS configuration for the host `BBRWAX9`, split into small modules.

## Layout

| File | Purpose |
| --- | --- |
| `configuration.nix` | Entry point: imports, networking, firewall, Nix GC, locale, user account |
| `vars.nix` | Values shared across modules (username) |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`; machine-specific, don't edit by hand |
| `boot-hardware.nix` | Bootloader, kernel, graphics, Bluetooth, peripherals, printing |
| `storage.nix` | Extra disks, zram and swapfile |
| `desktop.nix` | Plasma 6, SDDM, PipeWire audio |
| `software.nix` | System packages, Steam, Flatpak, AppImage, nix-ld |
| `virtualization.nix` | libvirt/QEMU, Docker, Waydroid |
| `environment.nix` | Session variables, shell aliases, `vpn` launcher |

## Deploying

The aliases in `environment.nix` expect this repository at `~/.config/nixos`:

```sh
git clone https://github.com/oversouth/NixConfig ~/.config/nixos
sudo nixos-rebuild switch -I nixos-config=$HOME/.config/nixos/configuration.nix
```

After the first switch, `rebuild` runs the same command and `nixconf` opens
`configuration.nix` in `micro`.

## Bootstrapping a new machine

1. Install NixOS and clone this repo to `~/.config/nixos`.
2. Regenerate the hardware file for the new machine:
   `sudo nixos-generate-config --show-hardware-config > ~/.config/nixos/hardware-configuration.nix`
3. Update the machine-specific values: the games disk UUID in `storage.nix`
   and the hostname in `configuration.nix`.
4. Run the `nixos-rebuild switch` command above.

## Notes

- The firewall is enabled. Open ports explicitly in `configuration.nix`.
- The `vpn` command launches NekoBox from an AppImage already extracted by
  `appimage-run`. Run the AppImage once with `appimage-run` before first use.
